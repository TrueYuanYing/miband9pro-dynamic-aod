# 探索历程

| 阶段 | 遇到的困难 | 尝试与结果 | 得到的判断 |
|---|---|---|---|
| 找回原工程 | 早期 BIN 没有预期 AOD 页面 | 从保留工程和原素材查找 | 原文件不可覆盖，先区分素材与导出内容 |
| 亮屏及AOD页面 | 白屏卡住、人物串帧、绿色空页面 | 调整页面格式、资源与图层；V13能显示时间日期星期 | 页面正确不代表动画调度正确 |
| native与Lua动画 | AOD只停首帧，分钟更新时才改变 | V14/V15尝试Image动画与计时器，未获得持续刷新 | 普通表盘逻辑缺少持续AOD调度 |
| 固件研究 | 没有可验证的整机修改固件 | 分析原版3.1.175，局部执行调度链；未刷改造OTA | 不能把离线分支测试说成可安全刷固件 |
| 多轮诊断 | 固件/对象/MPU/缓存/入口需要核对 | 只读probe从黑页到正确AOD页面，取得版本与对象匹配证据 | 页面、内存布局、执行权限要分别验证 |
| 自动原生模块 | 表盘需接通原生加载和调度 | V16.2获自动动态AOD实机成功反馈 | 保留原始启动模板与线程内延迟初始化 |
| 提帧回归 | 直接改模块与目录后无震动、不动 | Restore Baseline恢复；Smooth在ready后的RAM调整间隔成功 | 原启动方式也是兼容条件 |
| V18/V19美术及压缩 | 组件色框、衣服残边、AOD灰底矩形、日期过近 | 分离色系与字形、统一衣服外轮廓、改透明PNG、内移日期 | 画布底噪会让OLED整块发亮 |
| V20性能 | 已能播放但仍卡 | 逐帧透明裁剪、原坐标复原，解码像素少52.85%；目标40ms | 实机FPS仍待确认，目标25fps不能当实测 |

历史以版本顺序组织，不编造每阶段的耗时、具体日期或故障次数。作者自有素材及表盘完整成品留在本地；仓库仅发布方法与通用代码。动态AOD成功有本项目的用户反馈，但没有跨机型或长期稳定性结论。
